# The Ivory Atelier

Bespoke digital invitations and event websites. Instagram: [@theivoryatelier.studio](https://www.instagram.com/theivoryatelier.studio/).

## Edit the website

- `index.html` — wording, sections, sample projects and links
- `style.css` — colours, typography, invitation artwork and responsive layout
- `script.js` — mobile navigation, sample dialogs and inquiry drafts

No installation or build is required. Open `index.html` to preview locally.

## Publish on GitHub Pages

In repository **Settings → Pages**, select **Deploy from a branch**, choose **main** and **/ (root)**, then save. `.nojekyll` lets GitHub publish the files as they are.

The inquiry form prepares a draft to copy into Instagram; it does not store or send submissions. Direct submission requires a form provider or server endpoint. All portfolio projects are explicitly labeled illustrative samples.

The preferred custom domain is `theivoryatelier.studio`. Do not configure a CNAME until the domain has been registered and ownership confirmed.
